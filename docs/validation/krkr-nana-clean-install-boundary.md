# Loca-Love and Nana clean-install boundary

Testing and adaptation of Loca-Love: My Cute Roommate, My Commuting Crush and
My Shrine Crush were paused on 2026-11-25.

The tested Windows edition of My Shrine Crush reached gameplay with its matching
local profile, table and startup companion. With the profile and table alone,
CrySirror opened the archive directory and startup failed before the title
screen. The prototype obtained its startup input from an activated original
Windows run. The tested clean installation has no demonstrated source of that
input in its installed files alone.

Keep the matching companions with the owner's local test materials. Public
fixtures for archive and launcher tests use synthetic data.

Resume this experiment when an edition supplies verifiable startup input
through its original files or the publisher supplies a supported input source.
Use the normal launcher on a fresh copy without the recovered companions and
verify all six XP3 mounts, the title menu and entry into the first scene.
Verify each target platform before extending the Windows result to that platform.
